# Loan Approval Analysis
Loan Approval Analysis using Python, SQL, and Power BI to identify factors influencing loan approval decisions.
## Project Overview
This project analyzes loan application data to understand the factors associated with loan approval decisions. The analysis was performed using Python, SQL, and Power BI to explore applicant characteristics, financial information, and approval patterns.
## Objective
- Analyze loan application data to identify factors associated with loan approval.
- Examine applicant, financial, and loan-related characteristics.
- Use Python, SQL, and Power BI to generate meaningful business insights.
- Present the findings through an interactive Power BI dashboard.
## Tools & Technologies
  - Python (Pandas, Numpy, Matplotlib, Seaborn)
  - Jupyter Notebook
  - SQL
  - Power BI
  - Github
 ## Data Preparation & Analysis
 The loan application dataset was cleaned and prepared in Jupyter Notebook using Python, Missing values, data types, and relevant data fields were reviewed before performing the analysis. The cleaned dataset was then used for SQL analysis and Power BI visualization.
 ## SQL Analysis
 SQL was used to analyze the cleaned loan application data and examine loan approval patterns. The analysis includes applicant characteristics, loan amounts, credit history, income, and other factors related to loan approval.
 ## Power BI Dashboard
 An interactive Power BI dashboard was created to present key loan approval metrics and analyze approval patterns across different applicant and loan characteristics.
The dashboard includes key performance indicators and visualizations covering loan approval status, applicant demographics, credit history, income, loan amount, education, self-employment, marital status, dependents, and property area.
## Key Business Insights
- Credit history is an important factor associated with loan approval outcomes.
- Applicant income and loan amount provide useful context when analyzing approval patterns.
- Applicant characteristics such as education, employment status,  marital status, dependents, and property area can be compared to understand differences in approval outcomes.
- The analysis provides a consolidated view of loan application and approval patterns using Python, SQL, and Power BI.
